# Golden Look v4 - 팀 공유용 변경 요약

이번 기획 변경으로 Golden Look의 AI 방향이 크게 바뀌었습니다.

## 1. 옷 입력

- Gemini 자연어 파싱 제거
- 사용자가 20색 팔레트에서 직접 선택
- 상의/하의/모자/신발 중심
- 옷 종류/브랜드는 선택 입력
- 소지품은 전단 텍스트용

## 2. 사진 모드 2개

사진 업로드 전 `얼굴만 나온 사진인가요?` 체크박스를 받습니다.

- 체크 X: 몸이 나온 사진 → Gemini 이미지 편집으로 옷 **색 + 형태** 변경
- 체크 O: 얼굴만 나온 사진 → 나이/키/성별/체형을 받아 **예상 몸 생성**

## 3. 결과

- 결과 문구: **AI로 재현한 예상 모습**
- 자연스럽게 서 있는 자세
- 배경은 최대한 유지
- 생성 결과가 마음에 안 들면 재생성 최대 3회

얼굴-only에서 옷 종류를 입력하지 않으면 AI가 로고/과한 패턴 없는 중립적 기본 의상을 사용합니다. AI가 임의로 만든 의상 종류를 사실 정보처럼 전단 글자에 추가하지 않습니다.

## 4. AI 기술

- Gemini 텍스트 분석은 사용하지 않음
- Gemini **이미지 생성/편집 API**가 baseline
- 기존 SegFormer/LAB/Modal은 필수 구조에서 제거

## 5. AI 담당자 권한

AI 담당자는 구현 방식을 최대한 자유롭게 바꿀 수 있습니다.

자유 변경:
- 모델/provider
- prompt
- SDK/언어
- 폴더 구조
- AI pipeline/후처리
- retry/timeout/품질 개선

최소 제약:
- `body_visible` / `face_only` 의미 유지
- 앱이 요청/결과를 연결할 수 있는 interface 유지
- Secret/개인정보 로그 금지
- 결과에 `AI로 재현한 예상 모습` 표시
- 재생성 최대 3회

API/DTO, 환경변수, DB/Storage, Frontend 입력처럼 다른 팀에 영향을 주는 변경만 **변경 후/PR 전에 보고**합니다. 실험 자체를 막지는 않습니다.

## 6. 기존 정책 유지

- Email/Password MVP 로그인
- 카카오/Google 로그인은 추후
- 112/182 제거
- 자체 제보는 추후
- 전화번호 전체 공개 + 발행 전 확인
- 작성자만 자신의 전단 삭제

## 한 줄 결론

> Golden Look v4는 ‘옷 색만 변경’이 아니라, **몸이 있는 사진은 당일 옷차림으로 편집하고 얼굴 사진만 있으면 예상 몸까지 생성하는 AI 실종 모습 재현 서비스**로 진행합니다.
